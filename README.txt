JEZLEEN SECURITY V4 - CATÁLOGO EDITABLE

1. Abre index.html para ver la página.
2. Entra a admin.html para administrar productos.
3. Contraseña inicial del panel: jezleen2026
4. Los productos se guardan en el navegador mediante localStorage.
5. Puedes exportar el catálogo a JSON para hacer respaldo o llevarlo a otro navegador.
6. Puedes importar ese JSON en otro navegador.

IMPORTANTE: esta versión es ideal para una web estática. Para que varios dispositivos compartan el mismo catálogo en Internet y las imágenes queden almacenadas en un servidor, el siguiente paso es conectar el panel a una base de datos/backend.
